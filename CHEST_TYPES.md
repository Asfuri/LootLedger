# Chest types — updated 6 November 2026 (v0.4)

Types now come from the **Unreal class of each container in your replays**, not from appearance. Classes observed in 100 replays from Fortnite build 43.00 (Treasure Hunters season) where someone searched or broke open the container:

| Class | Shown as | Searched or broken (all players) |
|---|---|---:|
| `Tiered_Chest_Athena_C` | Chest | 4,887 |
| `AlwaysSpawn_NormalChest_C` | Chest | 2,602 |
| `Tiered_Ammo_Athena_C` | Ammo box (not a chest) | 1,315 |
| `AlwaysSpawn_RareChest_C` | Rare chest | 647 |
| `B_Athena_BuriedChest_Chest_C` | Buried chest | 344 |
| `B_TieredChest_Relics_C` | Relic chest | 332 |
| `FoodBox_Produce_Athena_C` | Food box (not a chest) | 42 |
| `B_SpritePosters_Booty_Chest_C` | Sprite poster chest | 27 |
| `Tiered_Chest_5_Child_C` | Chest | 12 |
| `B_Delilah_TieredChest_Relics_Variant1_C` | Relic chest | 9 |
| `Barrel_FishingRod_Container_Athena_C` | Fishing barrel (not a chest) | 8 |
| `B_Athena_BuriedChest_RelicFinder_C` | Buried chest | 4 |

The display names paraphrase the class names; Epic does not publish an official list. Any new class containing "Chest" is counted as **Other chest** under its own class name in the entry details, so a new seasonal chest is counted rather than missed. You can rename an entry's type on the Openings page.

Epic's [Treasure Hunters announcement](https://www.fortnite.com/news/fortnite-treasure-hunters-the-greatest-adventure-of-all-time?lang=en-US) mentions Captain X's mega chest. No class for it appeared in these replays; if it appears in yours, it will show as Other chest unless its class matches a pattern above.
